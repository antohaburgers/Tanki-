# Стальная волна

Плоский статический HTML5/Canvas MVP танкового roguelite. Все файлы находятся в корне и работают на GitHub Pages без сборки и сервера.

## Запуск

Откройте `index.html` через локальный статический сервер либо опубликуйте содержимое корня репозитория на GitHub Pages. ES-модули браузер блокирует при открытии через `file://`, поэтому для локальной проверки нужен сервер, например `python3 -m http.server 8000`.

## Управление

- ПК: `W/S` — вперёд/назад, `A/D` — поворот корпуса, мышь — башня, ЛКМ — огонь, `Space` — супервыстрел, `Esc` — пауза.
- Телефон: левый стик — движение, правый — направление башни, кнопки — огонь и супервыстрел. Рекомендуется альбомная ориентация.

## Состав MVP

Три последовательные волны, одна усиливающаяся модель противника, тяжёлый танк-босс в третьей волне, стрельба и столкновения, HP и броня, разрушимые ящики, выбор из трёх апгрейдов после волн, заряд супервыстрела за убийства, HUD, пауза, победа/поражение и перезапуск без перезагрузки страницы. Графика и эффекты рисуются Canvas-кодом; внешние ресурсы не нужны.

Баланс лежит в `config.js`. `DEBUG` включается через `debug: true` там.
